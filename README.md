# Solvent Recommendation System (Version 1)

## Overview
This project is a Python-based rule system that recommends suitable organic solvents for chemical reactions based on polarity, reaction type, and toxicity levels.

## How it works
- Loads solvent data from a CSV file  
- Defines reaction rules (SN2, E1, etc.)  
- Filters solvents based on reaction requirements  
- Converts toxicity into numeric values  
- Sorts solvents by toxicity  
- Displays recommended solvents  

## What I learned
- Python functions and modular design  
- Working with CSV files  
- Dictionaries and lists for data modeling  
- Building a simple data pipeline  
- Sorting and filtering logic  

## Limitations
- Limited reaction types (SN2, E1 only)  
- Simplified chemical modeling  
- Toxicity scale is basic  
- No GUI (terminal-based only)
